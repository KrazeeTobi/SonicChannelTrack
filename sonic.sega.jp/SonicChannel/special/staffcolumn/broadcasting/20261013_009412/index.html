TOKYO GAME SHOW 2026！ソニックを追いかけて会場を駆け回ってきたぞ！

2026.10.13

やあ！ソニックチャンネルWebマスターのKIKUZOだ！

今年もやってきた、TOKYO GAME SHOW 2026！

会場にはゲームもステージも展示も盛りだくさん。
もちろん、ソニックもあっちへこっちへ大活躍だ！

ということで今回は、ソニックブースを中心に、会場で見つけたソニックたちの様子をバシッとお届けしていくぞ！

まずはソニックブースへ！

到着したら、まずはソニックブースをチェック！
今年は『ソニックレーシング クロスワールド』と『SONIC PICO PARK』を展示していたぞ。

『ソニックレーシング クロスワールド』では、シーズン2を大きくアピール！
しかも試遊台は、特別仕様の縦型モニター！
大きな画面いっぱいに広がるレースは、会場で見るとなかなかの迫力だ。

そして、こちらは『SONIC PICO PARK』！
TGS会場で4人で遊んだけど、2名～8名でみんなでワイワイ遊べるのがポイントだ。

さらにブースには......
ソニックとピコキャットも登場！

ゲームの中だけじゃなく、会場でも一緒だ！

世界大会ファイナリストに挑戦だ！

続いてはファンタイムショウ！
開催されたのは、「ソニック 世界大会ファイナリストに挑戦！【ソニックレーシング クロスワールド】」だ！

ステージには、世界大会ファイナリストに加えて、ソニック総合プロデューサーの飯塚さん、『ソニックレーシング クロスワールド』クリエイティブディレクターの小早川さん、ZETA DIVISIONのLazさん、そしてもちろん、ソニックが登場！

そして始まったのが、
世界大会ファイナリストチーム VS ソニック&Lazチーム！の『ソニックレーシング クロスワールド』対決
世界大会のファイナリストが相手とは......これは強敵だぞ！

ソニック&Lazチームにはハンデが用意された状態での対決。
そして結果は......
ソニック&Lazチームの勝利！！

やったぞソニック！
世界大会ファイナリストとの勝負の様子は、動画でも見ることができるので、こちらもチェックしてくれよなっ！

今度はZETA DIVISIONブースへ！

まだまだ終わらないぞ！
次に向かったのはZETA DIVISIONブース。
ここでは、SONIC VS k4senの3番勝負が行われたぞ！
体内時計対決、音速ステップ対決、最後は『ソニックレーシング クロスワールド』の直接対決だ！

着々と試合が進み...最後は『ソニックレーシング クロスワールド』の対決！

大型モニターには両者のレースが映し出され、二人の真剣な勝負が始まったぞ！
さて、結果は......？

ソニック勝利！！

さすがソニック！
......と、ここまではよかったのだが。
その後、なんとソニックのZETA DIVISION脱退が報じられるという展開に！

試合の結果&何が起きたのか気になる人は、こちらの動画で確認してくれ！

そしてZETA DIVISIONブースでは、星野さんとソニックグッズも発見！
ブースに設置されたカメラで記念撮影をしていたぞ！

TGS30周年！ソニックチームからもお祝い！

そして今年は、TOKYO GAME SHOWにとって特別な年。
TGS30周年！
会場に展示されていた記念の寄せ書きには、ソニックチームからのメッセージも！

こういう展示をじっくり探してみるのも、会場を歩く楽しみのひとつだな。

今年もソニックを追いかけて走り回ったぞ！

ソニックブースから始まって、ファンタイムショウ、ZETA DIVISIONブース、そしてTGS30周年記念展示まで。
気がつけば、今回もソニックを追いかけて会場をあっちへこっちへ！
『ソニックレーシング クロスワールド』で熱いレースを繰り広げたかと思えば、『SONIC PICO PARK』ではみんなでワイワイ。そしてステージに飛び出せば、世界大会ファイナリストやk4senとの真剣勝負！
今年もいろんな場所で、ソニックらしいスピード感たっぷりの姿を見ることができたぞ。

以上、TOKYO GAME SHOW 2026のソニックレポートをお届け！
また次のイベントでも、ソニックを見つけたらバシッとレポートしていくから、楽しみにしていてくれよなっ！
